Інтерактивний урок: Перевірка умов у Python (if, elif, else)

📚 Що таке умовні оператори?

У програмуванні часто виникає потреба виконувати різні дії залежно від певної умови. Для цього в Python використовують конструкцію розгалуження:

  • if — перевіряє початкову умову. Якщо вона істинна (True), виконується блок коду всередині нього.
  • elif (скорочення від *else if*) — перевіряє додаткову умову, якщо попередні виявилися хибними.
  • else — спрацьовує тоді, коли жодна з попередніх умов не виконалася.

Приклад коду на Python:

x = 10

if x > 0:
    print("Число додатне")
elif x < 0:
    print("Число від'ємне")
else:
    print("Це нуль")
